### Worktree and simulator cleanup

**You own the disk and the safety gate.** Prune merged or abandoned git worktrees and stale iOS simulators to reclaim space. Deletion is irreversible, so every step guards against deleting something in use or holding uncommitted work.

1. Snapshot and audit. Record `df -h /`. Use `session_store_sql` to resolve recent sessions scoped to this repository and collect only the worktree paths they used. If it is unavailable, inspect only explicitly resolved session IDs under `~/.copilot/session-state/<session-id>/`. Write the exact recent-worktree paths to a file in the active session workspace, then pass it as the second argument to `scripts/worktree-audit.sh` (principle-build-the-lever). The script reads candidates from `git worktree list`, classifies size, age, merge state, uncommitted work, remote and PR state, and exact recent-session use, then suggests a bucket.
2. The bucket is advice, not permission. Active sessions are the real artifact (principle-prove-it-works). Cross-check every candidate against runtime task status and any user-pinned work the runtime exposes. If pinned state is unavailable and it changes the deletion decision, follow [User decisions](../references/task-contract.md#user-decisions). Use `ask_user` when available. Otherwise ask one concise plain-text question with numbered hold or delete choices and end the turn. Keep the candidate held until approval arrives.
3. Verify usage before deleting. Treat every `verify-session-unknown` row as held until session use is resolved. For every `verify-recent-session` row, or anything you doubt, read only the exact session IDs already scoped to this repository. For a large set, read `../references/task-contract.md` and issue no-write `general-purpose` tasks together, each with explicit session IDs and worktree paths (principle-guard-the-context-window). Never scan all session-state directories.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and follow [User decisions](../references/task-contract.md#user-decisions). Use `ask_user` when available. Otherwise ask one concise plain-text question with numbered keep or delete choices and end the turn. Do not delete without approval because uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Per Autonomy, clean and merged and not-in-use proceeds; `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`; if the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`; package caches such as pnpm, uv, brew, and yarn. Do not treat `~/.copilot/session-state` as a generic cache. Clear only state the user has approved or the tool can prove disposable.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in use by which session, or uncommitted work).
